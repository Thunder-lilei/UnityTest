# 设置界面开发方案

## 1. 目标

为游戏增加暂停菜单 + 设置界面，支持音频音量调节（主音量/音效音量）、暂停/继续/重启/退出游戏。设置项通过 PlayerPrefs 持久化，下次启动自动加载。不涉及 BGM。

## 2. 现状分析

### 2.1 现有暂停机制

项目已有两处暂停逻辑，均使用 `Time.timeScale = 0` + `SetPaused(true)` 模式：

| 场景 | 触发 | 恢复 | 涉及脚本 |
|---|---|---|---|
| 升级选择 | 经验满自动触发 | 点击卡片后 | UpgradeSystem.cs → PlayerMovement/PlayerCombat/MeleeCombat.SetPaused() |
| 游戏结束 | 血量归零 | 点击重新开始 | PlayerHealth.cs → Time.timeScale=0, ShowGameOver() |

### 2.2 现有音频系统

`AudioManager.cs`（单例）管理 12 个独立 AudioSource 字段，均为 SFX 音效，无 BGM，无音量控制接口。

### 2.3 现有场景层级

场景根节点无统一管理节点。`AudioManager` 和 `LuaManager` 各自独立在场景根级：

```
场景根
├── Main Camera
├── Directional Light
├── Player
├── Canvas
├── AudioManager          ← 根级独立节点（11 个子 AudioSource）
├── LuaManager            ← 根级独立节点
├── EnemySpawner
├── ...（其他场景对象）
```

**问题**：场景重载（RestartGame）时 AudioManager 会被销毁，音量设置丢失。需要新增 `GameManager` 根节点 + `DontDestroyOnLoad` 解决。

### 2.4 鼠标状态

游戏运行时隐藏鼠标光标。暂停菜单需要鼠标操作按钮，暂停时需显示光标，恢复时重新隐藏。

### 2.5 关键约束

- `EnemySpawner.Update()` 使用 `Time.deltaTime`，`Time.timeScale = 0` 时自然暂停
- `EnemyMovement` 依赖 NavMeshAgent，`timeScale = 0` 时 NavMeshAgent 不会更新
- 暂停菜单需与升级面板互斥：升级面板已激活时按 ESC 不应打开暂停菜单

## 3. 架构设计

### 3.1 新增脚本

| 脚本 | 命名空间 | 职责 |
|---|---|---|
| `PauseMenu.cs` | `Game.UI` | ESC 键开关暂停菜单，管理暂停/恢复，鼠标光标显隐，按钮回调 |
| `SettingsManager.cs` | `Game.Systems` | 管理音量设置（主音量/音效），读写 PlayerPrefs，应用到 AudioManager |

### 3.2 修改脚本

| 脚本 | 修改内容 |
|---|---|
| `AudioManager.cs` | 新增 `SetMasterVolume / SetSFXVolume` 方法；`Awake` 中从 PlayerPrefs 加载音量并应用；新增 `DontDestroyOnLoad` |

### 3.3 新增场景节点

新增 `GameManager` 空节点作为管理脚本根节点，将 `AudioManager` 移至其下：

```
GameManager (新增, DontDestroyOnLoad)
├── AudioManager          ← 从根级移入
│   └── (11 个子 AudioSource)
└── (PauseMenu 和 SettingsManager 挂在 Canvas 上，不在此节点下)
```

**GameManager 职责**：
- 空 GameObject，仅作为管理脚本的容器
- 挂载 `DontDestroyOnLoad` 确保 AudioManager 在场景重载时存活
- AudioManager.Awake() 中调用 `DontDestroyOnLoad(gameObject)` 自身即可，GameManager 节点本身不需要额外脚本

> **简化方案**：不在 AudioManager 外再包一层 GameManager，直接在 AudioManager.Awake() 中调用 `DontDestroyOnLoad(gameObject)`。AudioManager 已是根级独立节点，加一行即可实现跨场景持久化。

### 3.4 类关系

```
PauseMenu (ESC 触发, 挂在 Canvas 上)
  ├── 暂停 → Time.timeScale=0 + SetPaused(true) + Cursor.visible=true
  ├── 恢复 → Time.timeScale=1 + SetPaused(false) + Cursor.visible=false
  ├── SettingsManager (音量设置)
  │     ├── 读写 PlayerPrefs (master/sfx volume)
  │     └── 应用到 AudioManager
  │           ├── masterVolume → AudioListener.volume
  │           └── sfxVolume → 各 SFX AudioSource.volume
  ├── PlayerHealth.RestartGame() (重启)
  └── PlayerHealth.QuitGame() (退出)
```

### 3.5 暂停互斥逻辑

```
ESC 按下时:
  if (upgradePanel.activeSelf) → 忽略（升级中不响应 ESC）
  else if (gameOverPanel.activeSelf) → 忽略（游戏结束不响应 ESC）
  else if (pauseMenu.activeSelf) → Resume()
  else → Pause()
```

### 3.6 鼠标光标管理

```
游戏开始:    Cursor.visible = false,  Cursor.lockState = Locked
暂停菜单:    Cursor.visible = true,   Cursor.lockState = None
恢复游戏:    Cursor.visible = false,  Cursor.lockState = Locked
游戏结束:    Cursor.visible = true,   Cursor.lockState = None（已有逻辑或补充）
```

## 4. 功能清单

### 4.1 暂停菜单

| 元素 | 类型 | 功能 |
|---|---|---|
| 半透明遮罩 | Image (黑色 50% 透明) | 遮挡游戏画面 |
| 标题 "已暂停" | TextMeshProUGUI | 居中显示 |
| 继续游戏 | Button | 恢复 timeScale=1 + SetPaused(false) + 隐藏面板 + 隐藏鼠标 |
| 设置 | Button | 隐藏暂停菜单，显示设置面板 |
| 重新开始 | Button | 调用 PlayerHealth.RestartGame() |
| 退出游戏 | Button | 调用 PlayerHealth.QuitGame() |

### 4.2 设置面板

| 元素 | 类型 | 范围 | 持久化 Key |
|---|---|---|---|
| 主音量 | Slider (0~1) | 0.0001 ~ 1.0 | `Volume_Master` |
| 音效音量 | Slider (0~1) | 0.0001 ~ 1.0 | `Volume_SFX` |
| 返回 | Button | — | 隐藏设置面板，回到暂停菜单 |

**音量应用规则**：
- 主音量 → `AudioListener.volume`（全局，影响所有声音）
- 音效音量 → 各 SFX AudioSource.volume（最终 source.volume = sfxVolume）
- Slider 值为 0 时设为 0.0001（非完全静音，避免 AudioSource 被引擎优化停止）
- 默认值：masterVolume=1.0, sfxVolume=1.0

## 5. 实施步骤

### Step 1: 扩展 AudioManager

修改 `AudioManager.cs`：

1. 新增字段 `private float masterVolume = 1f, sfxVolume = 1f;`
2. `Awake()` 中：
   - 从 PlayerPrefs 读取上次保存的音量值
   - 调用 `DontDestroyOnLoad(gameObject)` 实现跨场景持久化
   - 应用初始音量
3. 新增方法：
   ```csharp
   public void SetMasterVolume(float v)   // AudioListener.volume = v; masterVolume = v; PlayerPrefs.SetFloat("Volume_Master", v);
   public void SetSFXVolume(float v)       // 遍历所有 SFX AudioSource 设 volume = v; sfxVolume = v; PlayerPrefs.SetFloat("Volume_SFX", v);
   ```
4. 收集所有 SFX AudioSource 引用（fireballLaunch, fireballHit, enemyDeath, playerHurt, playerDeath, pickupExp, levelUp, gameOver, healthPotionPickup, upgradeConfirm, dash, slashAttack），`SetSFXVolume` 遍历设置

### Step 2: 创建 SettingsManager 脚本

`Assets/Scripts/SettingsManager.cs`（命名空间 `Game.Systems`）：

1. 持有 2 个 Slider 引用（主音量/音效）
2. `Start()` 中从 PlayerPrefs 加载值，设置 Slider 初始位置，应用到 AudioManager
3. Slider 的 `onValueChanged` 回调 → 实时应用到 AudioManager + 写入 PlayerPrefs
4. `OnDestroy()` 确保 `PlayerPrefs.Save()`

### Step 3: 创建 PauseMenu 脚本

`Assets/Scripts/PauseMenu.cs`（命名空间 `Game.UI`）：

1. 持有 `pauseMenuPanel`、`settingsPanel`、`upgradePanel`、`gameOverPanel` 引用
2. 持有 `playerMovement`、`playerCombat`、`meleeCombat` 引用（用于 SetPaused）
3. `Start()` 中初始化鼠标状态：`Cursor.visible = false; Cursor.lockState = CursorLockMode.Locked;`
4. `Update()` 检测 ESC 键（`KeyCode.Escape`），执行互斥逻辑
5. `Pause()` → timeScale=0 + SetPaused(true) + 显示面板 + `Cursor.visible = true; Cursor.lockState = CursorLockMode.None;`
6. `Resume()` → timeScale=1 + SetPaused(false) + 隐藏面板 + `Cursor.visible = false; Cursor.lockState = CursorLockMode.Locked;`
7. `OpenSettings()` / `CloseSettings()` → 面板切换
8. `RestartGame()` → 调用 PlayerHealth.RestartGame()
9. `QuitGame()` → 调用 PlayerHealth.QuitGame()

### Step 4: 创建 UI 面板

在现有 Canvas 下创建：

```
Canvas
├── (现有 UI: HealthBar, ExpBar, UpgradePanel, GameOverPanel, TimerText ...)
├── PauseMenuPanel        ← 默认隐藏
│   ├── DimBackground (Image, 黑色 50% 透明, 全屏)
│   ├── Title "已暂停" (TextMeshProUGUI)
│   ├── ResumeButton     → PauseMenu.Resume()
│   ├── SettingsButton   → PauseMenu.OpenSettings()
│   ├── RestartButton    → PauseMenu.RestartGame()
│   └── QuitButton       → PauseMenu.QuitGame()
└── SettingsPanel        ← 默认隐藏
    ├── DimBackground (Image, 黑色 50% 透明, 全屏)
    ├── Title "设置" (TextMeshProUGUI)
    ├── MasterVolumeLabel  + MasterVolumeSlider
    ├── SFXVolumeLabel     + SFXVolumeSlider
    └── BackButton         → PauseMenu.CloseSettings()
```

### Step 5: 场景配置

1. AudioManager 节点保持根级，Awake 中 DontDestroyOnLoad

4. 将 SettingsManager.cs 挂到 SettingsPanel 上，配置 Slider 引用

## 7. 注意事项

1. **AudioSource volume vs AudioListener.volume**：AudioListener.volume 是全局的，各 AudioSource.volume 是相对的。最终音量 = listener.volume × source.volume。Master Slider 控制 listener 层面，SFX Slider 控制 source 层面。
2. **Slider 最小值**：设为 0.0001 而非 0，避免 AudioSource 在 volume=0 时被引擎优化停止播放，导致后续调高音量时无法恢复。
3. **PlayerPrefs 首次运行**：无存档时使用代码中的默认值（master=1, sfx=1），不弹窗不报错。
4. **DontDestroyOnLoad**：AudioManager 已是根级独立节点，在 Awake() 中调用 `DontDestroyOnLoad(gameObject)` 即可。场景重载后 AudioManager 实例存活，音量设置不丢失。但需注意：单例模式中 `if (Instance == null) Instance = this;` 会在新场景中检测到旧实例仍存活，不会重复创建。
5. **鼠标光标**：游戏开始时 `Cursor.visible = false; Cursor.lockState = CursorLockMode.Locked;`。暂停时切换为 `None + visible`。恢复时切回。游戏结束面板也需要鼠标操作，需确保 PlayerHealth.ShowGameOver() 中也解锁鼠标（如尚未解锁）。
6. **ESC 键冲突**：当前项目未使用 ESC 键做其他功能，无冲突。
7. **TMP 字体**：面板中的中文文字（"已暂停"、"设置"、"继续游戏"等）需要 TMP 中文字体支持。项目已配置微软雅黑中文字体，直接使用即可。但不要在 UI 文字中使用 Emoji 符号（如 ❤⚡🔥），SDF 字体不支持。
