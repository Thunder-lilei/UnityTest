# 溶解特效制作教程

> **目标**：敌人死亡时身体从边缘逐渐溶解消失，溶解边界发光
> **技术方案**：手写 URP HLSL Shader + 脚本动画控制
> **引擎版本**：团结引擎 2022.3 (URP 14.2.0)

---

## 技术原理

**三层结构：Shader（算法）→ 材质（参数）→ 脚本（驱动）**

### Shader（Dissolve.shader）— GPU 上每个像素做什么

```
UV × NoiseScale → simpleNoise() → 噪声值(0~1)
                                        ↓
clip(噪声 - DissolveAmount)  → 低于阈值的像素丢弃
                                        ↓
|噪声 - DissolveAmount| ÷ EdgeWidth → 边缘因子(0~1)
                                        ↓
lerp(贴图颜色, 发光颜色, 边缘因子) → 最终颜色
```

核心机制：噪声决定形状，DissolveAmount 控制进度，边缘处发光。Shader 只管"给定一个 DissolveAmount 画出对应效果"，不管动画速度。

### 材质（DissolveMat.mat）— 配置参数

| 参数 | 值 | 作用 |
|------|-----|------|
| DissolveAmount | 0（初始） | 溶解进度，脚本运行时修改 |
| NoiseScale | 30 | 噪声颗粒密度 |
| EdgeWidth | 0.1 | 发光边缘宽度 |
| EdgeColor | 橙红色 | 烧蚀边缘颜色 |
| BaseMap | 脚本传入 | 敌人原始贴图 |

### 脚本（DissolveEffect.cs）— 运行时驱动

敌人死亡时触发：

```
禁用碰撞/寻路/动画
    ↓
替换材质 → 每个敌人独立材质实例（避免互相影响）
    ↓
传入原始贴图和颜色给溶解材质
    ↓
协程逐帧推进：
  每帧 elapsed += Time.deltaTime（真实流逝时间）
  DissolveAmount = elapsed / dissolveDuration（进度比例 0→1）
  传给 Shader
    ↓
elapsed >= dissolveDuration → 销毁 GameObject
```

`dissolveDuration` 是唯一的速度控制参数——1.0 秒走完 0→1 就是 1 秒溶解完。

---

溶解效果由三部分组成：

1. **噪声控制溶解形状**：用伪随机函数 `frac(sin(dot(uv, float2(12.9898, 78.233))) * 43758.5453)` 生成 0~1 的噪声值
2. **Alpha Clip 丢弃像素**：`clip(noise - _DissolveAmount)` — 当噪声值 < 阈值时丢弃像素。阈值从 0→1 动画，可见区域从全部→无
3. **边缘发光**：噪声值接近阈值的像素（即溶解边界）混合发光颜色

```
噪声值:   0.2  0.5  0.8  0.3  0.9
阈值=0.4:  裁剪  可见 可见 裁剪 可见
                     ↑发光        ← 0.5-0.4=0.1 在边缘宽度内 → 发光
```

## 第一部分：Dissolve.shader（已完成）

Shader 文件已创建在 `Assets/Shaders/Dissolve.shader`，包含两个 Pass：

### ForwardLit Pass（主渲染）

| 步骤 | 代码 | 作用 |
|------|------|------|
| 1 | `simpleNoise(uv * _NoiseScale)` | 生成 0~1 噪声值 |
| 2 | `clip(noise - _DissolveAmount)` | 噪声 < 阈值的像素直接丢弃 |
| 3 | `1.0 - saturate(abs(noise - _DissolveAmount) / _EdgeWidth)` | 计算边缘因子（0=远离边界，1=在边界） |
| 4 | `SAMPLE_TEXTURE2D(_BaseMap, ...)` | 采样原始贴图 |
| 5 | `lerp(baseColor, _EdgeColor, edgeFactor)` | 混合基础色和发光色 |

### ShadowCaster Pass（阴影）

溶解过程中仍能投射部分阴影，与主 Pass 使用相同的 clip 逻辑。

### 属性列表

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `_BaseMap` | Texture2D | white | 敌人原始贴图 |
| `_BaseColor` | Color | (1,1,1,1) | 贴图染色 |
| `_DissolveAmount` | Range(0,1) | 0 | 溶解进度（脚本动画驱动） |
| `_EdgeWidth` | Range(0,0.5) | 0.1 | 发光边缘宽度 |
| `_EdgeColor` | Color | (1,0.4,0,1) | 边缘发光颜色（橙红色） |
| `_NoiseScale` | Range(1,100) | 30 | 噪声密度 |

## 第三部分：DissolveEffect.cs 脚本

在 `Assets/Scripts` 目录创建 `DissolveEffect.cs`：

```csharp
using System.Collections;
using UnityEngine;

/// <summary>敌人死亡溶解特效：替换材质 → 动画 DissolveAmount 0→1 → 销毁</summary>
public class DissolveEffect : MonoBehaviour
{
    [Tooltip("溶解材质")]
    public Material dissolveMaterial;

    [Tooltip("溶解持续时间（秒）")]
    public float dissolveDuration = 1.0f;

    private SkinnedMeshRenderer[] renderers;

    void Awake()
    {
        renderers = GetComponentsInChildren<SkinnedMeshRenderer>();
    }

    /// <summary>启动溶解：替换材质 → 动画 → 销毁</summary>
    public void StartDissolve()
    {
        // 1. 禁用碰撞体和寻路
        GetComponent<Collider>().enabled = false;
        var agent = GetComponent<UnityEngine.AI.NavMeshAgent>();
        if (agent != null) agent.enabled = false;

        // 2. 禁用动画
        var anim = GetComponent<Animator>();
        if (anim != null) anim.enabled = false;

        // 3. 替换所有 SkinnedMeshRenderer 的材质为溶解材质
        foreach (var smr in renderers)
        {
            // 为每个 renderer 创建材质实例（避免共享材质互相影响）
            Material matInstance = new Material(dissolveMaterial);

            // 传入原始贴图和颜色
            if (smr.sharedMaterial != null && smr.sharedMaterial.mainTexture != null)
            {
                matInstance.SetTexture("_BaseMap", smr.sharedMaterial.mainTexture);
                matInstance.SetColor("_BaseColor", smr.sharedMaterial.color);
            }

            smr.material = matInstance;
        }

        // 4. 启动溶解动画
        StartCoroutine(DissolveCoroutine());
    }

    /// <summary>逐帧增加 DissolveAmount 从 0 到 1，完成后销毁</summary>
    IEnumerator DissolveCoroutine()
    {
        float elapsed = 0f;

        while (elapsed < dissolveDuration)
        {
            float t = elapsed / dissolveDuration;

            foreach (var smr in renderers)
            {
                if (smr.material != null)
                    smr.material.SetFloat("_DissolveAmount", t);
            }

            elapsed += Time.deltaTime;
            yield return null;
        }

        // 确保 DissolveAmount 到达 1（完全消失）
        foreach (var smr in renderers)
        {
            if (smr.material != null)
                smr.material.SetFloat("_DissolveAmount", 1f);
        }

        // 延迟一帧后销毁
        yield return null;
        Destroy(gameObject);
    }
}
```

### 脚本说明

| 步骤 | 做了什么 | 为什么 |
|------|---------|--------|
| 禁用 Collider | 敌人不再参与碰撞 | 溶解过程中不应被火球命中或阻挡玩家 |
| 禁用 NavMeshAgent | 停止寻路 | 敌人已死，不应再移动 |
| 禁用 Animator | 停止动画 | 溶解过程中保持死亡时的姿势 |
| 创建材质实例 | `new Material(dissolveMaterial)` | 每个敌人独立材质，动画进度互不影响 |
| 传入原始贴图 | `SetTexture("_BaseMap", ...)` | 溶解材质需要知道敌人长什么样 |
| 逐帧 SetFloat | DissolveAmount 从 0→1 | 驱动 Shader 的溶解进度 |

## 第四部分：集成到 EnemyMovement.cs

### 4.1 添加 DissolveEffect 组件

1. 在场景中选中敌人 Prefab（如 `Assets/Models/Quaternius Zombie Apocalypse Kit/quaternius_zombie_apocalypse_kit_zombie_basic.prefab`）
2. Inspector → Add Component → 搜索 `DissolveEffect` → 添加
3. 将 `Assets/Shaders/DissolveMat` 拖入 Dissolve Material 槽位
4. 对 EnemyTank、EnemyBoss 的 Prefab 重复上述操作

### 4.2 修改 Die() 方法

打开 `Assets/Scripts/EnemyMovement.cs`，找到 `Die()` 方法。

**修改前**（当前的 Die 方法最后两行）：

```csharp
        if (healthBarInstance != null)
            Destroy(healthBarInstance);

        Destroy(gameObject);
```

**修改后**：

```csharp
        if (healthBarInstance != null)
            Destroy(healthBarInstance);

        // 触发溶解特效（替换直接销毁）
        var dissolve = GetComponent<DissolveEffect>();
        if (dissolve != null && dissolve.dissolveMaterial != null)
            dissolve.StartDissolve();
        else
            Destroy(gameObject);
```

> **逻辑**：如果有 DissolveEffect 组件和材质，走溶解流程；否则兜底直接销毁。

## 第五部分：验证与调参

### 5.1 测试

1. 保存所有修改

4. 用火球消灭敌人
5. 观察：敌人死亡时身体应从边缘开始逐渐溶解消失，边界有橙红色发光

### 5.2 参数调整

| 参数 | 位置 | 调整效果 |
|------|------|---------|
| NoiseScale | 材质 Inspector | 值越大噪声越细密，溶解边缘越碎；值越小噪声越粗大，溶解块越大 |
| EdgeWidth | 材质 Inspector | 发光边缘宽度。0.05 = 细边，0.3 = 宽边 |
| EdgeColor | 材质 Inspector | 边缘颜色。可改为蓝色做"冰冻溶解"、绿色做"毒蚀溶解" |
| dissolveDuration | DissolveEffect 组件 | 溶解持续秒数。0.5s 快速、2.0s 慢动作 |

### 5.3 常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 敌人完全不可见 | DissolveAmount 默认值不是 0 | 选中材质，确认 Dissolve Amount = 0 |
| 溶解时敌人变纯黑/纯白 | BaseMap 未指定贴图 | 确认脚本正确传入原始贴图（检查 smr.sharedMaterial.mainTexture） |
| 边缘没有发光 | EdgeWidth 太小 | 增大 EdgeWidth 到 0.15~0.2 |
| 溶解后敌人不消失 | 协程未执行 | 检查 Console 无报错，确认 DissolveEffect 组件已添加 |
| 溶解形状是条纹/方块 | NoiseScale 太小或太大 | 调到 20~50 范围 |
