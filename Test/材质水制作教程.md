# 材质水（Shader Graph 河流）制作教程

> 适用项目：迷你游戏（URP + 瓦片地图河流）
> 目标：用 URP Shader Graph 制作流动河水材质，替换当前河流瓦片的静态材质
> 效果：UV 滚动模拟水流方向 + 法线扰动模拟波纹 + 透明度 + Fresnel 边缘高光

---

## 前置准备

### 1. 准备水纹理贴图

需要两张贴图（可通过 AI 生成材质或从网上下载免费 PBR 贴图）：

| 贴图 | 用途 | 推荐尺寸 |
|---|---|---|
| 水面颜色贴图（Albedo） | 水的基础颜色（浅蓝/青绿色） | 512×512，可平铺 |
| 水面法线贴图（Normal） | 波纹凹凸效果 | 512×512，可平铺 |

**推荐资源**：
- 免费贴图网站：https://opengameart.org 搜索 "water texture seamless"
- 或用 AI 生成：`generate_material` preset_id="sand"（或自定义 prompt "seamless water surface texture, blue green, calm ripples"）
- 或直接用程序化噪声（本教程也包含纯噪声方案，无需贴图）

### 2. 确认 URP Shader Graph 可用

- 项目已安装 `com.unity.render-pipelines.universal` 14.2.0-t1
- Shader Graph 包含在 URP 中，无需额外安装

---

## 步骤一：创建 Shader Graph

1. **Project 窗口** → 右键 `Assets/Shaders/` 目录
2. 选择 **Create > Shader Graph > URP > Unlit Shader Graph**
   - 为什么用 Unlit：水材质自己控制透明度和颜色，不需要场景光照影响（如果需要光照反应可用 Lit Shader Graph）
3. 重命名为 `WaterFlow.shadergraph`

---

## 步骤二：配置 Shader 属性

打开 Shader Graph 编辑器，在 **Blackboard**（左侧面板）添加以下 Property：

### 2.1 添加 Properties

| Property Name | Type | Default Value | 说明 |
|---|---|---|---|
| `MainColor` | Color | (0.1, 0.4, 0.6, 0.8) | 水的基础颜色（半透明青蓝） |
| `FlowSpeed` | Float | 0.5 | 水流速度 |
| `FlowDirection` | Vector2 | (1, 0) | 水流方向（UV 偏移方向） |
| `NormalStrength` | Float | 0.5 | 法线扰动强度 |
| `FresnelPower` | Float | 3.0 | 边缘高光强度 |
| `Opacity` | Float | 0.7 | 整体透明度 |
| `NormalTex` | Texture2D | None | 法线贴图（可选，无则用程序化噪声） |

### 2.2 设置 Graph Settings

在 Shader Graph 编辑器顶部 **Graph Inspector**：

| 设置项 | 值 | 说明 |
|---|---|---|
| Surface | Transparent | 透明材质 |
| Blend Mode | Alpha | Alpha 混合 |
| Double Sided | ✅ | 双面渲染（从水下看也可见） |
| Cast Shadows | ❌ | 水不投影 |
| Depth Write | ❌ | 不写入深度缓冲 |

---

## 步骤三：搭建 UV 滚动节点网络

这是水的核心效果——让贴图持续向一个方向滚动，产生流动感。

### 3.1 时间节点驱动偏移

1. 创建 **Time** 节点（右键 → Create Node → 搜索 "Time"）
2. 创建 **Multiply** 节点，将 `Time` 的 `Time` 输出 × `FlowSpeed` 属性
3. 创建 **Multiply** 节点，将上一步结果 × `FlowDirection` 属性
4. 创建 **UV** 节点（使用默认 UV0）
5. 创建 **Add** 节点，将 `UV` + 上面计算的偏移量
6. 将 `Add` 的输出连接到后续贴图的 `UV` 输入

```
[Time] ──× [FlowSpeed] ──× [FlowDirection] ──┐
                                                +──> [UV offset] ──> 贴图 UV
[UV] ─────────────────────────────────────────┘
```

### 3.2 双层 UV 滚动（增强真实感）

水面上叠加两层不同速度方向的 UV，模拟水面层次：

1. **第一层**：FlowDirection=(1,0)，FlowSpeed=0.5（主流方向）
2. **第二层**：FlowDirection=(0.7,0.3)，FlowSpeed=0.3（次流方向，略偏）
3. 两层贴图采样结果用 **Lerp** 或 **Add** 混合

---

## 步骤四：法线扰动（波纹效果）

### 方案 A：使用法线贴图

1. 创建 **Sample Texture 2D** 节点
2. 将 `NormalTex` 属性连到其 `Texture` 输入
3. 将步骤三的滚动 UV 连到其 `UV` 输入
4. 创建 **Normal Vector** 节点（Create Node → "Normal Vector"）
5. 将采样结果 × `NormalStrength` 后连到 Normal Vector
6. 将 Normal Vector 连到 Fragment 的 `Normal`（如果用 Lit Shader Graph）

### 方案 B：程序化噪声（无需贴图）

1. 创建 **Simple Noise** 节点（Create Node → "Simple Noise"）
2. 将滚动 UV 连到 Simple Noise 的 `UV` 输入
3. 创建第二个 Simple Noise 节点，用不同 UV 缩放（×2）
4. 用 **Add** 混合两层噪声
5. 将噪声输出 × `NormalStrength`，连到 Fragment 的 `Normal` 或 `Alpha`

---

## 步骤五：Fresnel 边缘高光

Fresnel 效果让水面边缘（掠射角）更亮，中心更暗，模拟反射：

1. 创建 **Fresnel Effect** 节点（Create Node → "Fresnel Effect"）
2. 将 `FresnelPower` 属性连到 `Power` 输入
3. 将 Fresnel 输出连到 Fragment 的 `Emission`（让边缘发光）

---

## 步骤六：颜色混合与输出

### 6.1 组合最终颜色

1. 创建 **Lerp** 节点
2. `A` 输入 = `MainColor`（基础水色）
3. `B` 输入 = 白色（或浅蓝色，边缘高光色）
4. `T` 输入 = Fresnel 输出
5. 将 Lerp 结果连到 Fragment 的 `Base Color`

### 6.2 设置透明度

1. 创建 **Multiply** 节点
2. `A` = `MainColor` 的 Alpha 通道（Split 节点提取）
3. `B` = `Opacity` 属性
4. 将结果连到 Fragment 的 `Alpha`

---

## 步骤七：保存并创建材质

1. 点击 Shader Graph 编辑器左上角 **Save Asset**
2. 回到 Project 窗口，右键 `WaterFlow.shadergraph` → **Create > Material**
3. 重命名为 `WaterFlow.mat`，放在 `Assets/Materials/`

---

## 步骤八：应用到河流瓦片

### 方法一：直接替换河流材质（简单）

项目中河流瓦片有独立的 Prefab（`Assets/Prefabs/River.prefab` 或瓦片地图的 River Tile）：

1. 选中河流 Prefab
2. 在 Inspector 中找到 MeshRenderer 组件
3. 将 `WaterFlow.mat` 拖到 `Materials` 数组的 Element 0
4. Apply Prefab

### 方法二：通过脚本批量替换（推荐）

如果河流由多个瓦片组成，写脚本批量替换：

```csharp
using UnityEngine;
using UnityEditor;
using UnityEditor.SceneManagement;

public class ReplaceRiverMaterial : MonoBehaviour
{
    [MenuItem("Tools/Replace River Material")]
    static void Replace()
    {
        var waterMat = AssetDatabase.LoadAssetAtPath<Material>("Assets/Materials/WaterFlow.mat");
        if (waterMat == null)
        {
            Debug.LogError("WaterFlow.mat not found!");
            return;
        }

        // Find all river tile objects
        var grid = GameObject.Find("Grid");
        if (grid == null) return;

        int count = 0;
        foreach (var renderer in grid.GetComponentsInChildren<MeshRenderer>())
        {
            if (renderer.gameObject.name.Contains("River"))
            {
                renderer.sharedMaterial = waterMat;
                count++;
            }
        }

        Debug.Log($"Replaced material on {count} river tiles");
        EditorSceneManager.MarkSceneDirty(EditorSceneManager.GetActiveScene());
        EditorSceneManager.SaveScene(EditorSceneManager.GetActiveScene());
    }
}
```

## 步骤九：调试与优化

### 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 水面不可见 | 透明度太低 | 调高 Opacity 到 0.8-0.9 |
| 水流方向不对 | UV 方向与河流走向不匹配 | 调整 FlowDirection 的 Vector2 值 |
| 波纹太强 | NormalStrength 太大 | 降到 0.2-0.3 |
| 水面闪烁 | UV 滚动速度太快 | 降低 FlowSpeed 到 0.2-0.3 |
| 水面透过地面 | Depth Write 关闭导致 | 在河流下方放一个不透明底面 |

### 性能优化

| 优化项 | 说明 |
|---|---|
| 贴图尺寸 | 512×512 足够，河流不需要高分辨率 |
| LOD | 如果河流很长，远处的瓦片可以用更简单的材质 |
| 关闭阴影 | 水材质不要 Cast Shadows |

## 进阶效果（可选）

### 添加焦散（Caustics）

在水底地面添加焦散光斑动画：
1. 创建另一个 Shader Graph，用噪声纹理 + UV 滚动模拟焦散
2. 将焦散材质应用到河流下方的地面瓦片
3. 或在后处理中用 Screen Space 方式投射

### 添加水面泡沫

在河流边缘（河岸瓦片）添加白色泡沫效果：
1. 用噪声纹理 + 阈值裁剪生成泡沫遮罩
2. 在 Shader 中用 `Step` 或 `Smoothstep` 节点控制泡沫范围
3. 泡沫颜色叠加到 Base Color 上

### 水面反射

用 URP Planar Reflection 或 Screen Space Reflection 实现水面反射：
- Planar Reflection：渲染一个翻转的 Camera 到 RenderTexture，精度高但性能消耗大
- SSR：后处理方式，适合浅水面

## 完整节点连接图（文字版）

```
[Time] ──────────────────────────────────────────────────────────────
  │                                                                  │
  × [FlowSpeed]                                                      │
  │                                                                  │
  × [FlowDirection]                                                 │
  │                                                                  │
  ┌─ Layer 1 ──────────────────────────────────────────────────────┐ │
  │  [UV] + [Time×Speed×Dir] ──> [SampleTex NormalTex] ──> [Normal] │ │
  └────────────────────────────────────────────────────────────────┘ │
                                                                      │
  ┌─ Layer 2 (offset dir) ──────────────────────────────────────────┐│
  │  [UV] + [Time×Speed×0.3×Dir2] ──> [SampleTex NormalTex] ──> ───┘│
  └─────────────────────────────────────────────────────────────────┘ │
                                                                      │
  [Fresnel] ──× [FresnelPower] ────────────────────────────────────────┘
      │
      ├──> [Lerp A=MainColor B=White T=Fresnel] ──> Fragment.BaseColor
      │
      └──> Fragment.Emission

  [MainColor.Alpha] × [Opacity] ──> Fragment.Alpha
```
