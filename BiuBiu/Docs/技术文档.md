# BiuBiu 技术实现文档

> 本文档介绍 BiuBiu 项目的核心、关键与特殊玩法、设计的技术实现，面向需要深入维护/扩展本项目的开发者。
> 配套文档：`数值文档.md`（全部可调参数与手感口径）、`设计文档.md`（玩法设计决策与 GameFeel 表）。
> 代码约定：Built-in Render Pipeline、C#、TextMeshPro（DOM 提示）、IMGUI（HUD）、ScriptableObject 驱动配置（`GameBalance` 静态常量类）、对象池、单例管理器、热重载自愈。

---

## 1. 架构总览

### 1.1 场景与装配
- **Boot 场景**：仅含 `GameBootstrap`（单例，持有本局 `PlayerStats` 与本局统计），负责进入 Main 场景。
- **Main 场景**：**不手摆玩法对象**。由 `RuntimeSceneBuilder` 在运行时装配——生成相机（带 `CameraFollow` + `AudioListener`）、玩家、地图（`MapGenerator2D` 生成边界墙 + 俄罗斯方块掩体）、HUD、各管理器。
- 装配顺序保证管理器 `Awake` 先于玩法对象，避免空引用。

### 1.2 管理器清单（单例模式）
| 管理器 | 职责 | 访问点 |
|---|---|---|
| `GameBootstrap` | 本局玩家属性/统计、玩家引用 | `GameBootstrap.Instance.GetPlayer()` |
| `GameController` | 游戏状态机（菜单/进行/暂停/结算）、轮次推进 | 单例 |
| `EnemySpawner2D` | 敌人生成、活跃列表、剩余计数、轮次配置 | 单例 |
| `ObjectPool` | 通用对象池（按 prefab 实例 ID 分池） | 静态类 |
| `CameraTrauma` | 镜头震屏（trauma 值趋近叠加） | 单例 |
| `AudioManager` | 音频播放（含 2D/3D 世界音、循环音） | 静态类 |
| `SpeechBubbleManager` | 头顶冒泡文本（数据驱动文案） | 静态入口 `Say()` |
| `BreakBurstManager` | 击碎/撞墙像素碎片爆发 | 静态入口 `SpawnBreakBurst()` |
| `DropManager` | 血迹/尸体池（FIFO 超龄销毁） | 单例 |
| `SaveSystem` | 最高轮次/最多击杀（JSON 文件 `save.json`） | 静态类 |

### 1.3 热重载自愈
所有管理器采用 `Instance == null` 判空重建或 `FindObjectOfType` 惰性获取，场景热重载后不会因引用失效崩溃。HUD 对 `HurtVignette`、`player` 等引用均为惰性获取 + 缺失静默跳过。

## 2. 核心系统

### 2.1 对象池（`ObjectPool`）
- 静态类，按 **prefab 实例 ID** 分池（`Dictionary<int, Stack<GameObject>>`）。
- `Get(prefab, pos, rot)`：优先出栈闲置实例并 `SetActive(true)`、设置位姿；池空则 `Instantiate`。
- `Release(instance)`：失活并入栈。**约束：仅可释放本池 `Get` 出来的实例**；场景手摆对象禁止入池。
- 用途：玩家弹丸、敌人弹丸、碎片、血迹、尸体、残影等高频对象。

### 2.2 事件与解耦
- 无独立事件总线枚举。跨系统通信采用 **单例方法调用 + 静态事件委托**（如 `EnemySpawner2D.OnEnemyIntro`、`GameController` 状态回调）。
- 受击/击杀/轮次等通过直接调用管理器方法（`CameraTrauma.Instance.AddTrauma(...)`、`SpeechBubbleManager.Say(...)`）实现，保持轻量、无反射开销。

### 2.3 配置驱动（`GameBalance`）
- 全部可调数值集中在 `GameBalance` 静态常量/只读字段（移动速度、蓄力阈值、伤害、冷却、拖尾、碎片参数等）。
- 设计意图与对应数值文档章节写入注释，调参不需改逻辑代码。

## 3. 关键玩法实现

### 3.1 弹弓三段蓄力发射链路（`SlingWeapon` + `PlayerProjectile`）
**输入→档位**：左键按住进入蓄力，`chargeTimer` 累加，`chargeProgress` 归一化映射档位：
- `< 0.5s` → 白（0 级，速射）
- `≥ 0.5s` → 黄（1 级，击飞）
- `≥ 1s` → 红（2 级，击碎/秒杀普通敌人）

**蓄力拉拽位移**：蓄力期间玩家沿瞄准反方向缓慢后退（`PlayerController` 冻结常规移动，由 `SlingWeapon` 写入 `Rb.velocity`）。拉拽速度存于 `SlingWeapon.ChargePullVelocity`，**由 `PlayerController` 在蓄力分支统一写 velocity**（见 §6.4 漂移修复）。位移封顶 `ChargeMaxPullback`，避免长按倒退过远。`chargeOrb`（蓄力指示物，挂玩家子物体）随进度从起点拉远 + 放大 + 染色。

**发射（`Fire`）**：
1. 白档受 `WhiteFireCooldown`（0.3s）限频，连点过快吞掉发射（DPS 封顶）；黄/红无此限制。
2. 每轮攻击力微增（`PlayerStats.AttackBonusFloat` 向下取整）叠加到伤害。
3. 伤害公式：`level>=2 ? 4 : (level==1 ? 2 : 1) + attackBonus`。
   - 白=1（速射兜底）、黄=2（击飞控场）、红=4（对精英/Boss 高额伤害）。
4. `knockback`：仅黄档（1.5）生效，红档击飞走机制。
5. 弹丸经 `ObjectPool.Get(PlayerProjectile.Template)` 取出并 `Launch(dir, level, dmg, knockback, shatter)`。
6. 触发：发射冒泡、trauma 微震（`0.1*level`）、后坐力（`player.ApplyRecoil`）、三色发射音。

**弹丸飞行与命中（`PlayerProjectile`）**：
- 直线飞行（`velocity * dt` 更新位置），`TrailRenderer` 拖尾（三档差异，见 §5.3）。
- **撞墙/边界**：红档（满蓄）对可破坏掩体触发击碎；非满蓄或边界墙 → `SpawnWallSpark`（同色小碎片 + 轻脆音）后回收。
- **命中敌人**：
  - `shatter && !精英/Boss` → `enemy.Shatter()` 秒杀（无视血量），弹丸**穿透不消失**，`BreakBurstManager` 同色碎片爆发，trauma ×2。
  - `shatter && 精英/Boss` → 走高额伤害（满蓄不秒杀硬核），弹丸消失。
  - 非满蓄 → 普通扣血，弹丸消失。
- **过载脱手**（满蓄超 2s）：强制发射且红弹飞行方向随机偏移 ±40°（`OverchargeSpreadAngle`），表现"手滑飞偏"。

### 3.2 波次成长（`EnemySpawner2D` + `GameController`）
- 轮次从 1 起。每轮**清场**（剩余敌人为 0）才进下一轮（`RemainingEnemies` 静态读取活跃列表计数）。
- 登场规则（见数值文档）：第 3 轮起每轮 +1 精英；第 5、10 轮各 1 Boss；第 8 轮起数量封顶，转血量/精英占比。
- **每轮微增**：`PlayerStats` 移速 +0.5/轮、攻击力 +0.5/轮（浮点累积，伤害向下取整）。敌人血量随轮次提升。
- HUD 右上角显示当前轮次剩余敌人数量（普通+精英+Boss）。

### 3.3 敌人类型（均质化灰盒，差异在行为/配色）
基类 `EnemyBase2D` 统一状态机：`Seek → Windup(前摇预警) → ArcSweep(攻击) → Recover → Seek`，以及 `ChargeWindup`（精英冲撞）、Boss 专属八方向横扫/冲撞。
- **近战**：120° 大扇形前摇 0.9s，预警窗口供翻滚。
- **远程**：直线弹（`Projectile2D`）。
- **精英**：紫色，八方向投掷封锁，投掷距离 = 普通远程 ×2；攻击前摇不被击退打断。
- **Boss**：金色，第 5/10 轮登场；八方向扇形横扫（240°·r4）+ 直线冲撞，带 `sweepFill`/`chargeFill` 预警线框。
- **配色**：`GreyColor(enemyType)` 返回主色（普通=浅蓝 `(0.45,0.72,0.85)`、精英=紫、Boss=金），驱动血条、受击闪白、破碎粒子、**屏幕外箭头颜色**、尸体染色（`CorpseTint` 暗蓝）。

### 3.4 可破坏掩体（`DestructibleObstacle` + `MapGenerator2D`）
- 地图散布俄罗斯方块（Tetromino）形状障碍，用 `GreyBoxFactory` 生成的"大理石"像素 sprite（运行时 `CreateMarbleSprite`）。
- 边界墙不可破坏，且为满蓄力弹丸的**反弹面**（`PlayerProjectile` 反射 `velocity`，`maxBounces` 按档位 2/3/4）。
- 满蓄力弹丸命中掩体 → `DestructibleObstacle` 击碎 + 灰白同色碎片 + `stone_break` 音。
- 非满蓄力撞墙 → 迸发火花 + 轻脆音，弹丸消失。

## 4. 特殊反馈系统设计

### 4.1 受击红边（`HurtVignette` + `GameHud.DrawHurtVignette`）
- `HurtVignette` 运行时生成**径向渐变贴图**（中心透明、边缘红色晕影），挂在玩家受击时 `CurrentAlpha` 强度。
- HUD 在 `OnGUI` 最底层铺满全屏：`GUI.color = (0.85,0.08,0.08, intensity)` × 贴图 alpha。受击越强/连击越多红边越浓，提供"快死了"的方向无关警示。

### 4.2 屏幕外敌人方位指示（`GameHud.DrawOffscreenIndicators`）
- 遍历 `EnemySpawner2D.ActiveEnemies`（已排除尸体）。
- 世界坐标 → `Camera.main.WorldToScreenPoint` → 转 GUI 坐标（左上原点）。
- **屏幕外判定**：`sp.z>0 && 0<=x<=w && 0<=y<=h` 之外即屏外。
- **边缘锚点**：从屏幕中心指向敌人的方向 `dir`，与留白矩形（margin=30px）求交得 `edge`（标准矩形边界交点算法：`t = min((halfW-margin)/|dir.x|, (halfH-margin)/|dir.y|)`）。
- **朝向**：三角贴图绕 `edge` 旋转 `atan2(dir.y,dir.x)`。
- **颜色**：取 `enemy.MainColor`（与敌人同色），alpha 随距相机距离渐变（刚出视野=1.0，超出 2 倍视野半径→0.2），近实远淡。
- **尺寸**：固定 22px 三角，不随敌人强度变化。

### 4.3 翻滚冷却径向环（`GameHud.DrawRollCooldown`）
- 位置：左下角（margin 16px，环径 56px）。
- 底环：一次性生成 annulus 贴图（暗色整环 `RingBaseTexture`）。
- 进度弧：运行时生成 `CreateRingTexture(progress)`——从顶部（12 点）顺时针填充 `progress` 比例的亮弧（角度约定 `atan2(dx,-dy)`，顶部=0 顺时针递增），其余透明；带缓存（`_ringProgressCache`）避免每帧重生成。
- 就绪（`RollCooldownRemaining<=0`）：整环亮起 + 正弦 alpha 脉冲提示可用。
- 中心写"滚"字，不显示按键提示（左上角操作提示已含）。
- 数据来源：`PlayerController.RollCooldownRemaining` / `RollCooldownMax`。

### 4.4 翻滚残影（`PlayerController.AfterimageFader`）
- 翻滚触发时，在 `afterimageRoot` 下生成若干残影（复制玩家灰盒 sprite），`AfterimageFader` 组件自毁式渐隐（缩放/alpha 衰减，timer 归零销毁），表现高速位移残像。
- 翻滚含 0.3s 无敌帧，`RollCooldown=2.0s` 冷却（翻滚结束进入冷却）。

### 4.5 击碎破碎粒子（`BreakBurstManager` + `BreakShard`）
- 仅红档击碎触发（命中普通敌人或掩体）。
- 爆发 = **普通碎片 22 枚**（小、快、寿命 0.55s）+ **大块碎片 6 枚**（大、慢、寿命 0.8s），放射张角半角 π/2，沿弹丸飞行方向散开。
- 碎片经 `ObjectPool` 取出，`BreakShard` 匀速直线飞散（无重力、无碰撞）、缩小+渐隐、timer 归零回池。
- 着色取**敌人/墙主色**（`enemy.MainColor` / `Color.gray`），与灰盒同源。

### 4.6 弹丸拖尾（`PlayerProjectile` TrailRenderer）
- 三档差异：`TrailTime = {0.12, 0.22, 0.35}s`，`TrailWidth = {0.3, 0.45, 0.7}`。
- 红档粗光带（尾长≈4.9 tile），强化"满蓄霸气"视觉。
- 材质 `Sprites/Default`（透明混合），`sortingLayer=Effects`（与碎片同层），`sortingOrder=18`（略低于弹丸本体 20）。

### 4.7 蓄力过载与冒泡
- **过载抖动**：满蓄后 `overchargeTimer` 累加，`CameraTrauma` 目标从 0.45 随按住时间爬升至 0.95（每帧逼近），过载路径额外 ×2.0 位移/旋转倍率（仅满蓄，不波及受击/击杀全局震屏）。
- **冒泡**：满蓄超 `OverchargeWarnTime=1.0s` 且未提示过 → `SpeechBubbleManager.Say(player, Overcharge)` 显示"要憋不住了！"（`overchargeWarned` 标志，仅一次，`CancelCharge` 重置）。

### 4.8 头顶冒泡（`SpeechBubbleManager`）
- 数据驱动：`Resources/Data/Speech/speech.txt` 以 `Speaker.Event : 文案A | 文案B` 格式配置，多条文案随机选。
- `Say(target, speaker, event)` 在目标头顶锚点（默认 +0.8）生成气泡，定时渐隐。

## 5. 相机、物理与音频

### 5.1 相机跟随（`CameraFollow`）
- 正交相机平滑跟随玩家（位置插值），不旋转、不缩放（用户确认镜头表现满意，不加镜头特效）。

### 5.2 镜头震屏（`CameraTrauma`）
- `trauma` 值 0~1，各系统调用 `AddTrauma(amount)` 叠加（受击强震、击杀/击碎中震、发射微震、满蓄过载爬升）。
- 实际位移/旋转偏移 = `trauma²` 曲线（小震不明显、大震才剧烈），过载路径额外乘倍率。

### 5.3 物理与移动（`PlayerController`）
- 玩家用 `Rigidbody2D.velocity` 驱动移动（非直接设 transform），与墙碰撞由物理引擎处理。
- **velocity 唯一写入权**收归 `PlayerController`：翻滚 > 后坐力(`ApplyRecoil` 用 `MovePosition`+清零) > 蓄力拉拽(`SlingWeapon.ChargePullVelocity`) > 常规移动 > 静止清零。每帧仅一个分支写，消除多脚本抢写空窗（见 §6.4）。
- 受击击退：玩家被敌人弹丸命中扣血 + 轻微击退（红边提示）。

### 5.4 音频（`AudioManager`）
- 区分 2D（UI/HUD）与 3D 世界音（`PlayWorld`，按距离衰减、视野外剔除）。
- 已接入：蓄力循环音（`PlayLoop`/`StopLoop`）、三档发射音、闪避音、敌人受击/死亡/击碎音、撞墙轻脆音、石头破碎音。
- 音量层级：命中 < 发射 < 击杀，让重要事件更"跳"。

## 6. 已知约束与实现注意

### 6.1 IMGUI HUD 性能
- 全部 HUD（红边、血条、文字、边缘箭头、冷却环）走 `OnGUI`，每帧重绘。运行时生成贴图（心形、三角、环）均缓存/单例，避免每帧 `Texture2D` 分配。箭头贴图带进度缓存，仅比例变化 >1% 时重生成。

### 6.2 对象池约束
- 仅释放 `ObjectPool.Get` 出来的实例；场景手摆对象（如玩家）不入池。
- 池实例 `Initialize`/`Reset` 须复位所有运行状态（含 `isDead`、`baseColor`、`overchargeWarned` 等），避免回池复用串味。

### 6.3 颜色语义集中
- 敌人主色单一来源 `GreyColor`，驱动血条/闪白/碎片/箭头/尸体，改配色只动一处。
- 注意：击飞状态临时变蓝 `(0.4,0.8,1.0)` 与浅蓝普通敌人 `(0.45,0.72,0.85)` 刻意拉开，避免本体与击飞态撞色。

### 6.4 蓄力漂移修复（关键 bug）
- **根因**：`PlayerController.Update` 与 `SlingWeapon.Update` 都写同一 `Rb.velocity` 且执行顺序不定；蓄力中 `PlayerController` 见 `IsCharging` 直接 `return` 不碰 velocity，在 `IsCharging` 翻转帧（true→false）产生 velocity 空窗，物理步用过期/混合速度滑一帧 = 漂移。
- **根治**：`SlingWeapon` 暴露 `ChargePullVelocity`，`PlayerController` 蓄力分支改为**每帧显式写** `Rb.velocity = ChargePullVelocity`（不再单纯 return）；`CancelCharge` 末尾清零 + 复位 `ChargePullVelocity` 作双重保险。velocity 所有权唯一且连续，空窗闭合。

### 6.5 敌人蓄力框残留修复
- **根因**：敌人近战前摇（`State.Windup`）被击退时，`Knockback` 把状态改回 `Seek` 但未调 `HideWindupArc()`，扇形预警框（`windupArcOutline`/`windupArcFill`）残留。
- **修复**：`Knockback` 打断 `Windup` 分支加 `HideWindupArc()`。`Die`/`Shatter` 已调用，未击杀的 `TakeDamage` 不改状态故无残留。

### 6.6 SpriteFlash shader 构建裁剪修复
- **根因**：`Biubiu/SpriteFlash` shader 仅被 `HitFlash.cs` 的 `Shader.Find("Biubiu/SpriteFlash")` 字符串引用，项目无 `.mat` 材质直接引用它。Unity Build 管线认为该 shader 未被使用，构建时裁剪掉——编辑器中所有 shader 始终可用故正常，但 exe 中 `Shader.Find()` 返回 null，闪白材质创建失败，受击闪白静默失效。
- **修复**：将 `Biubiu/SpriteFlash` 加入 `ProjectSettings/GraphicsSettings.asset` 的 `m_AlwaysIncludedShaders` 列表，确保构建时不被裁剪。

## 7. 调参与扩展指引
- **改手感**：全在 `GameBalance`（移速、蓄力阈值、伤害、冷却、拖尾、碎片、震屏倍率）。
- **加敌人类型**：继承 `EnemyBase2D`，在 `GreyColor` 加配色分支，复用状态机与预警框。
- **加冒泡文案**：编辑 `speech.txt`，无需改代码。
- **加 HUD 元素**：沿用 `GameHud.OnGUI` + 运行时生成贴图模式（参考 `CreateRingTexture`/`CreateTriangleTexture`），不引入 Canvas。
- **加特效**：复用 `BreakBurstManager`（碎片）、`AfterimageFader`（残影）、`CameraTrauma`（震屏）既有通道。
