## 2. 工程建立与目录规范

### 2.1 工程创建

1. TuanjieEditor → 新建项目 → 模板选 **2D（URP）**（2D 光照/后期如需即用；若模板不可用则 Built-in，M0 记录实际选择）
   - **实际情况（2026-08-20）**：项目已建于 `UnityTest/BiuBiu`，模板为 **Built-in 2D**（manifest 无 URP 包）；已自带 2D 依赖（com.unity.2d.sprite / 2d.tilemap / feature.2d）；Input System 未装（M0-6 时安装）；闪白 shader 按 Built-in CG 语法编写
2. 项目名 `BiuBiu`
3. 工程路径下建立 Git 仓库（首次提交=空工程+`.gitignore`）

### 2.2 目录结构（Assets 根下平铺、PascalCase，与既有工程命名规范一致；第三方运行时按包自身路径落位）

```
Assets/
  Scripts/
    Core/            # GameBalance、GameBootstrap、对象池、存档、场景装配、震屏/跟随、闪白
    Player/          # 移动、翻滚、受击、成长属性（PlayerStats）
    Weapons/         # 弹弓蓄力武器（SlingWeapon）、主角弹丸（PlayerProjectile）
    Enemies/         # 刷怪器（波次制）、近战/远程/精英/Boss、能量弹、投掷物
    Drops/           # 地面血迹管理（DropManager）
    UI/              # HUD（局时/轮次/血量/消息框）、战报、暂停、设置
    Data/            # 数据定义（EnemyData 等 ScriptableObject 类；实例落在 Resources/Data/Enemies/，无独立 ScriptableObjects/ 目录）
  Art/              # 【已删除（2026-08-23）】原纯色 sprite / Spine / Tilemaps / VFX / UI 资产目录整体移除，当前无美术资产目录——所有视觉由运行时生成（GreyBoxFactory 灰盒 + GUI.DrawTexture + 运行时 Tile）
  Resources/
    Data/Enemies/    # EnemyData SO 实例（Resources 兜底加载）
  Scenes/            # 实际扩展名 .unity
    Boot.unity       # 引导场景（仅挂 [GameBootstrap] 单例，启动后切 Main；无开始页 UI，设置入口在暂停菜单与游戏内面板）
    Main.unity       # 大地图战斗（一局从头到尾单场景完成，无场景切换）
```

## 3. 渲染与相机设置（像素风基线）

| 项 | 设置 |
|---|---|
| 贴图导入 | Filter Mode=**Point**、Compression=**None**、Generate Mip Maps=**关** |
| PPU（Pixels Per Unit） | **32**（角色身高约 32~48px，tile=32px，1 tile=1 unit） |
| 相机 | 正交，Size=**9**（竖向约 18 tile 视野），背景色深色 |
| 像素完美 | Built-in 管线：`com.unity.2d.pixel-perfect` 包（相机挂 Pixel Perfect Camera 组件），M0 验证 |
| 排序 | 单一 Sorting Layer 体系：地面(-10)→血迹(-5)→影子(-4)→角色(0)→特效(5)→UI |
| 目标分辨率 | 1920×1080 窗口化优先，`RunInBackground=on` |

## 4. 核心代码架构约定

### 4.1 数值常量（唯一入口）

- `Core/GameBalance.cs` 静态类，与 `数值文档.md` **一一对应**，按文档章节分区注释；代码中禁止出现数值魔法数

### 4.2 数据驱动

| ScriptableObject | 内容 |
|---|---|
| `EnemyData` | 敌人（血量/移速/攻击/解锁时间；新增敌人=加配置不改代码） |

### 4.3 关键接口与模式

- `IDamageable`：一切受击统一入口（无敌模式在此拦截）
- 事件总线：`AudioEventChannel` 等 ScriptableObject 事件通道，解耦音频/特效触发（触发点清单=设计文档 12 章）
- 存档：**单一永久档**（`Core/SaveSystem.cs`，JSON 文件实现，路径=`Application.persistentDataPath/save.json` 即 AppData/LocalLow/DefaultCompany/BiuBiu/save.json）=历史最佳（仅两项：最大轮次 / 最多击杀）；**无中途档**（单局一命到底，关游戏=放弃本局，见设计文档 13.3）；成就系统与累计统计已取消（2026-08-24）
- GameState：单局运行时状态（轮次/局时/击杀）与永久纪录档分离
- 对象池：敌人、弹丸、投掷物、血迹、尸体全池化（设计文档 14 章）；弹丸/痕迹均有上限保护（数值文档 6 章）
- 随机数：`System.Random` 显式持有（地面变体撒点等）

## 5. M0 技术验证（当前阶段）

> 目标：排清引擎/管线风险，产出可玩原型（灰盒）。顺序即执行顺序，每项有验收标准；**任一项失败先记录再定绕行方案，不阻塞后续项**。

### M0-1 工程与渲染基线
- 做法：建工程→按第 2/3 章配置→导入一张 32×32 测试 sprite 跑通
- 验收：Point 采样无模糊、正交相机下像素对齐、窗口运行流畅

### M0-2 Spine 兼容性【最高风险 · 已废弃（2026-08-23）】
> 该里程碑项对应的 spine-unity 运行时（`Assets/Spine/`、`Assets/Spine Examples/`）已于 2026-08-23 整体删除，Spine 接入路线正式取消，灰盒为最终形态，本段仅作历史留痕。

### M0-3 受击闪白 shader
- 做法：自定义 shader（`_FlashAmount` 0↔1，约 10Hz）适配 Sprite/Mesh 渲染器
- 验收：渲染器整体变白↔原色切换；与枪火受光层叠加无冲突
- 进度（2026-08-21）：**完成，视觉验收通过**
  - `Assets/Art/VFX/Shaders/SpriteFlash.shader`（BiuBiu/SpriteFlash）：Built-in PMA 管线，`_FlashAmount` 在 PMA 空间 lerp 到闪白色（透明区不闪白）【注：该 shader 文件随 `Assets/Art/` 于 2026-08-23 删除，闪白改用运行时材质/MPB 实现，见 `HitFlash.cs`】
  - `Assets/Scripts/Core/HitFlash.cs`：MPB 驱动 10Hz 方波（`PlayFlash(时长)`），不实例化材质，Sprite/Mesh 渲染器通用

### M0-4 激光射线+反弹
- 做法：`Physics2D.Raycast` + `Vector2.Reflect`（反弹 1 次）+ LineRenderer 两段光束；测试墙体命中反射角
- 验收：判定与视觉同一路径、反弹角正确、命中敌人终止；接测试敌人按 tick 掉血 
- 附带验证：Additive 半月贴图枪火光照（开火强闪+持续微亮）
- 进度（2026-08-21）：**验收通过**（掉血 tick/反弹/反弹攻击/三层配色光束+命中微震全部正常；枪火光照顺延素材期）。踩坑：团结引擎同物体禁多个 LineRenderer → 三层光束各用子物体承载（BeamEdge/BeamMid/BeamCore）
  - `Assets/Scripts/Weapons/LaserWeapon.cs`：逐段 Raycast 推进（≤2 段）+ Reflect 反弹 1 次 + 剩余射程共享；判定与视觉共用同一 path（19.3 风险应对落地）；tick 0.2s/1 伤害
  - `Assets/Scripts/Core/IDamageable.cs`：统一伤害接口（开发者模式无敌预留入口）
  - `Assets/Scripts/Enemies/TestDummy.cs`：2 血木桩，受击闪白（串联 M0-3）+死亡 1s 复活
  - M0 场景激光验收台：Laser_Player（橙）+ DummyA（直射）+ 横墙/竖墙（反弹）+ DummyB（反射路径目标）（占位贴图 White32.png 已随 `Assets/Art/` 于 2026-08-23 删除）

### M0-5 Trauma 震屏
- 做法：纯代码模型（trauma 0~1、幅度=trauma²、噪声偏移+旋转、线性衰减）驱动相机
- 验收：受击强震/命中微震分级可感、衰减自然
- 进度（2026-08-21）：**验收通过**（1/2/3 三级震屏幅度递增衰减自然、激光命中微震正常、停止后完全复位）
  - `Assets/Scripts/Core/CameraTrauma.cs`：trauma 0~1 / 幅度=trauma² / 三路 Perlin 噪声（x/y/角度独立种子）/ 线性衰减 1.2/s / 每帧从基准变换叠加（无累积漂移）；参数：maxOffset 0.25 tile / maxAngle 4°
  - `Assets/Scripts/Core/TraumaTester.cs`：按 **1/2/3** 触发 微震 0.2 / 强震 0.5 / 超强震 0.8（分级对应设计文档 12 章）
