## 1. 项目概述

| 项目 | 内容 |
|---|---|
| 游戏名称 | BiuBiu（拟声词，弹弓弹丸发射/命中的声音） |
| 游戏类型 | 2D 像素风、俯视角、**幸存者类街机动作**（大地图波次刷怪、每轮自动变强、活得越久越险） |
| 引擎 | TuanjieEditor 1.9.3（团结引擎）；纯色几何 sprite（Spine 接入路线 v0.24 取消） |
| 目标平台 | Windows PC（单机，键鼠操作） |
| 元进度 | 【已定】仅历史最佳（最大轮次 / 最多击杀）跨局永久保留；**无局外成长**（不做基地、不做资源存量）；成就系统已取消 |
| 时间限制 | 【已定】无（无限生存，死亡即一局结束） |
| 难度方式 | 【已定】波次制+时间驱动：轮次数量指数翻倍（1→2→4→8），敌人血量随局时成长，玩家靠每轮自动微增对抗 |
| 交付物 | Windows 可玩版 + 工程源码 |
| 设计目标 | **战斗就是爽**——game feel 优先：打击感、反馈密度、"少量输入引发大量连锁反应" |

**一句话概述**：孙子站在敌人涌来的大地图中央——蓄力弹弓射击、翻滚闪避、每轮击杀后自动变强，看自己能活多久、杀多少。

**核心循环**（单局）：

```
开局（弹弓武器，出生在大地图中央，屏幕中心提示「记得攻击 记得闪避 好了 上吧！」）
   │
   ▼
波次制生存：第1轮1只→第2轮2只→第3轮4只→第4轮8只（2^(n-1)），类型随机
   击杀 → 全灭后自动属性微增（移速+0.5/攻击力+0.5）+回满血
   │                                    ↑
   ▼                                    └── 越战越强 ←→ 越来越险
精英 / Boss 周期登场（限时挑战）
   │
   ▼
死亡 → 战报结算（存活时长 / 等级 / 击杀数 + 历史最佳对比）
   → 再来一局 / 回到开始页
```

**设计支柱**：
1. **战斗手感是生死线**：蓄力弹弓要有分量，弹丸反弹+满蓄力击碎要爽；一切设计为"爽"让路
2. **单局即全部**：一命到底，无中途存档、无局外负担；输了立刻重开，重开零成本
3. **成长即时可见**：每轮全灭即自动变强（属性微增+回满血），无需任何选择打断战斗
4. **难度曲线自讲**：不做难度选项，时间本身就是难度；玩家自己决定"这局能走多远"

**资源策略**【已定：纯色几何+AI 生成为最终形态（2026-08-23 定案，原素材期流程取消）】：
- 【已定】**无正式素材制作计划**：全部素材除少量 AI 生成外均为纯色几何/临时贴图，且以此作为最终形态交付；原「冻结清单→单角色试点→量产」素材期流程取消；Spine 接入路线 v0.24 取消（玩家=灰盒圆点最终形态，`PlayerSpineAnimator` 已删除）
- 【已定】`素材需求文档.md` 已删除，不再维护素材规格需求
- 音效、特效：免费素材或 TuanjieAI 生成，按需接入
- 代码层事件驱动预留触发接口，资源到位即接入

## 2. 核心玩法循环【已定】

### 2.1 主循环

- 【已定】**无限生存**：一局从开局打到死亡，没有胜利条件；纪录=存活时长 / 达到等级 / 单局击杀数
- 【已定】**死亡即结算**：战报面板展示本局数据并与历史最佳对比（破纪录高亮），然后"再来一局 / 回到开始页"
- 【已定】**重开零成本**：从死亡到重新开战不超过 3 次点击（战报→再来一局）
- 【已定】**无中途存档**：单局一命到底；ESC 暂停仅暂停（含喝水休息场景），关游戏=放弃本局
- 【已定】**永久档仅存两项历史最佳**：最高轮次 / 单局最多击杀（2026-08-24 取消存活时长与累计统计、成就进度）

### 2.2 一局的节奏

```
0:00 开局：弹弓在手，2s 开场提示（「记得攻击 记得闪避 好了 上吧！」）后第 1 轮开始
第 N 轮 = 2^(N-1) 只敌人（三种类型随机混合）一次性刷出 → 全灭
   → 属性微增（移速+0.5/攻击力+0.5）+ 回满血 + 「第 N+1 轮！」提示 → 1s 后下一轮（数量翻倍）
3:00 首个精英登场（此后每 3 分钟一个，独立计时不占轮次配额）
5:00 首只 Boss 登场（此后每 5 分钟一只，一只比一只强，独立计时不占轮次配额）
…… 敌人血量随局时成长（时间即深度）+ 轮次数量指数翻倍 —— 与玩家的每轮微增赛跑
```

- 【已定】波次与成长数值详见 `数值文档.md` 第 7 章（7.2 波次制与每轮属性微增）
- 【已定】敌人血量成长公式详见 `数值文档.md` 第 6 章（时间难度曲线——v3.0 起仅驱动血量成长与精英/Boss 计时）
- 【已定】三种普通敌人**开局即混合出现**（M2 验收反馈定案 2026-08-22：无需延迟解锁；单敌登场提示不启用）

## 3. 大地图与刷怪【已定：大地图制】

### 3.1 地图

- 【已定】**单张大地图取代多房间关卡**：无房间边界、无门锁、无场景切换——一局从头到尾一张图
- 【已定】地图规格：**108×108 tile**（PPU 32 → 3456×3456px 可视世界），**边界墙环绕**（弹丸可反弹的墙体）
- 【已定】玩家出生在**地图正中央**
- 【已定】地面=森林地面 tile（批次 0 已交付的 2×1 合图：基础款 85% + 变体 15% 随机撒点）
- 【建议】地面装饰仅**稀疏静态点缀**（几丛草/石头 sprite，不可破坏、不阻挡移动），保持地面"安静"（地砖 QC 结论：低噪点不抢视觉焦点）
- 【已定】**场景内障碍墙（掩体）**（M2 验收反馈定案 2026-08-22，原「V1 不做」作废）：地图内部撒**俄罗斯方块（Tetromino）形状**障碍（7 种标准形状 + 旋转，带来长度与朝向变化）——带碰撞阻挡玩家与敌人（敌人靠物理滑动绕行，不做寻路）、**满蓄力弹丸命中可击碎**（同色碎片爆发 + 轻震屏）、非满蓄力命中迸发白/灰像素碎片 + 轻脆音、打破大地图空旷感；边界墙不可破坏仅做反弹面；撒点规格见 `数值文档.md` 第 12 章（避开出生点/边界墙/互相间距约束）

### 3.2 刷怪方式【已定：波次制（v3.0 重构）】

- 【已定】**波次制刷怪**：第 N 轮一次性刷出 2^(N-1) 只敌人（1→2→4→8→16…），类型从两类基础敌人（远程/近战横扫）中随机混合；刷出于屏幕外（正交相机视口矩形外扩 2 tile 的环形区域内随机取点），生成后向玩家追踪
- 【已定】**本轮全部被击杀 → 进入下一轮**：属性微增（移速+0.5/攻击力+0.5）+ 回满血 + 轮次提示语，间隔 1s 后刷出下一轮（数量翻倍）
- 【已定】**开场延迟 2s**：显示开场提示语（「记得攻击 记得闪避 好了 上吧！」）后才开始第 1 轮
- 【已定】**敌人血量仍随局时成长**（时间即深度）：难度级 = 存活时间 ÷ 30s，普通敌人血量 = 基础值 + floor(难度级 ÷ 4)（公式见 `数值文档.md` 第 6 章）；旧连续刷怪制的「刷怪间隔/同屏上限」公式已停用
- 【已定】精英每 3 分钟一只；Boss 每 5 分钟一只（**独立计时生成，不占轮次配额**）
- 【已定】**敌人数据 ScriptableObject 驱动**（EnemyData：血量/移速/攻击/解锁等），新增敌人=新增配置，不改代码
- 【已定】敌人出生即从屏幕外走向玩家；**离开屏幕过远的敌人不回收**（一直压过来形成包围）
- 【建议】敌人相互之间做轻度分离（避免完全重叠成一列），性能敏感时用简易网格分桶

## 4. 武器系统【已定：弹弓蓄力（v3.0 重构）】

### 4.1 总则【已定】

- 【已定】**唯一武器=弹弓**：按住左键蓄力 → 松开发射弹丸；无武器切换、无拾取/替换/丢弃流程
- 【已定】取消武器耐久
- 【已定】**蓄力期间玩家向瞄准反方向拉拽后退**（弹弓动作：人即是皮筋），松手即发射——拉拽既是视觉表现也是实际位移

### 4.2 两级蓄力机制【已定】

| 参数 | 一级（黄，0.5s） | 二级满（红，1.0s） |
|---|---|---|
| 定位 | 快速输出+击飞控场 | 高风险高回报：站桩 1 秒换取爆发 |
| 弹丸速度 | 9 tile/s | 14 tile/s |
| 最大反弹次数 | 1 | 3 |
| 伤害 | 1（命中消散） | 2，可**击碎**（秒杀普通敌人：无尸体+8 处扇形血迹） |
| 穿透 | 无 | **穿透敌人直到撞墙反弹用尽** |
| 击飞 | 1.5 tile | — |

- 【已定】**击飞连锁（v0.25 新增）**：黄色档击飞的敌人飞行期间撞到其他敌人，**传递碰撞击飞**（小位移 0.5 tile + 碰撞伤害 1），被撞敌人若也处于飞行态则继续连锁——形成"保龄球式"连锁反应。满蓄力击碎不连锁（瞬间秒杀无飞行体）。**两档蓄力体验完全分化：黄=连锁控场爽、红=单体爆发爽**
- 【已定】**弹丸反弹/交互规则**：边界墙与场景内障碍墙均为弹丸交互面——**满蓄力**命中内部障碍→击碎该障碍（弹丸消失不反弹）、命中边界墙→反弹（`Vector2.Reflect`）；**非满蓄力**命中任何墙→迸发同色像素碎片 + 轻脆音（弹丸消失）；命中敌人即结算（一级消散/二级穿透）
- 【已定】弹丸存活上限 5s、半径 0.3 tile；拉拽后退速度一级 1.0 / 二级 1.5 tile/s
- 【已定】蓄力视觉：玩家与瞄准点之间出现被拉拽的弹丸（黄→红随档位变色）；满蓄力红色饱和提示
- 【已定】数值详见 `数值文档.md` 4.1（弹弓蓄力武器）
- 武器池扩展：……（后续版本）

## 5. 成长系统【已定：每轮自动微增（v3.0 重构）】

### 5.1 v3.0 变更总览

- 【已定】**取消四选一升级面板**：不再积累经验条、不再弹卡选择——成长零打断
- 【已定】**经验概念整体移除（v0.23）**：无经验块掉落、无击杀经验入账——成长唯一来源=每轮结束自动属性微增
- 【已定】**等级（Lv）概念退役**：HUD/战报的局内进度口径统一为「第 N 轮」
- 【已定】旧四选一系统代码已删除（2026-08-23）：UpgradeDefinition SO×9、ExperienceSystem/UpgradeSystem/UpgradePanel 及 SO 资产一并清理

### 5.2 每轮自动微增【已定，待复核】

- 【已定】触发时机：**本轮敌人全部被击杀**的瞬间
- 【已定】效果：移速 +0.5 tile/s、攻击力浮点 +0.5，**回满血**（替代血瓶，见第 7 章）
- 【已定】表现：轮次提示语（「第 N 轮！我感觉好像强了一点点！」，屏幕右侧消息框）→ 1s 间隔 → 下一轮刷出（数量翻倍）
- 【已定】数值详见 `数值文档.md` 第 7 章（波次制与每轮属性微增）

### 5.3 成长方案【已定方向：战斗爽，待细化数值】

**设计目标**：成长让玩家**越往后打，蓄力击碎越频繁越爽**，而非让点射流也变强（否则蓄力失去意义）。

当前每轮 +0.5 移速 / +0.5 攻击的问题：

1. **攻击 +0.5 取整后白/黄弹丸第 2 轮变 2 伤**：近战 2 血=速射 1 发秒杀，**蓄力失去存在理由**——这与"战斗爽"背道而驰
2. **移速线性累加**：10 轮后 +5 tile/s，走位无压力→难度崩塌
3. **微增无感**：每轮 0.5 体感不到变强，违背"成长即时可见"

**已定方向（2026-08-23）**：

- **移速**：每轮 +0.5 保留（走位从容，支撑更长蓄力窗口的站桩走位）；但加封顶（+3 tile/s 上限，约第 6 轮封顶），防后期崩塌
- **攻击**：**不提升弹丸基础伤害**（白/黄恒 1、红恒 2），改为**降低蓄力档位阈值**——让满蓄力击碎更快达到、更频繁触发：
  - 第 1~2 轮：黄 0.5s / 红 1.0s（当前值）
  - 第 3 轮起：阈值随轮次递减（黄 0.4s→0.3s→…、红 0.8s→0.6s→…，有下限防瞬发）
  - 效果：后期满蓄力更快=击碎更频繁=爽点密度上升，但速射档仍需多发放杀敌人（蓄力动力保留）
- **击碎连锁（M3+ 可选扩展）**：满蓄力击碎后期可产生小冲击波波及周围敌人（轮次越高范围越大）——"战斗爽"的视觉爆点

**待用户确认的细节**：
- 蓄力阈值递减曲线（每几轮降一档、下限多少）
- 移速封顶值
- 击碎连锁是否做（M3 扩展项）

**未定前代码保持每轮 +0.5/+0.5 不动**，避免反复改。

## 6. 敌人设计【已定】

### 6.1 普通敌人【已定】

| 敌人 | 攻击形式 | 解锁时间 |
|---|---|---|
| 近战（横扫型） | 近战**横扫**（120° 大扇形，半径 2.0 tile，前摇 0.9s 渐红预警） | 0:00【开局混合】 |
| 远程（扔木头） | **远程**直线弹道，**蓄力弹弓式**（0.6s 反向拉拽→发射）；瘦高长方形 + 常驻 0 蓄力橙红圆球（半径同发射弹丸），每帧平滑环绕敌人朝玩家方向，蓄力时隐藏 | 0:00【开局混合】 |
| 近战（横扫型，木门板） | 近战**范围**横扫（120°，半径 2.0，前摇 0.25s） | 0:00【开局混合】 |

- 【已定】基础数值：普通 2 血/移速 3.6；投掷 2 血/移速 3.0/射程 6 tile；门板 3 血/移速 2.4（详见 `数值文档.md` 第 5 章）
- 【已定原则】**敌人血量随难度级成长**（时间即深度）：成长系数详见 `数值文档.md` 第 6 章

### 6.1.1 敌人间碰撞与连锁击飞【已定，v0.25 新增；v0.26 改物理驱动】

- 【已定】**敌人间物理碰撞**：敌人有 CircleCollider2D（非 trigger），Rigidbody2D Dynamic——敌人间物理推开防堆叠（拥挤感由物理天然表现，大量敌人涌现时自然挤推）
- 【已定】**击飞用物理冲量**（v0.26 改）：击飞不再直接覆写 `rb.velocity`，改用 `rb.AddForce`（ForceMode2D.Impulse 脉冲）——敌人飞行速度受质量影响，撞到其他敌人时物理引擎自然计算碰撞冲量传递（撞开=真实感）
- 【已定】**碰撞伤害传递**（v0.26 改）：被击飞中的敌人用 `OnCollisionEnter2D` 回调检测撞到的其他敌人，传递：
  - **碰撞击飞**：额外 `AddForce` 小冲量（区别于弹丸直击的大冲量）
  - **碰撞伤害**：1（与弹丸直击同，保证连锁也能杀敌）
- 【已定】**连锁衰减**：每跳传递冲量 ×0.6（< 阈值停止，防无限连锁）

### 12.2 特效补强想法【建议，待素材/实现】

当前战斗反馈偏“哑”（无声+无粒子），以下是提升打击感的特效补强点：

- **弹弓出膛闪光**：发射瞬间在枪口生成 0.03~0.05s 白色闪光 + 玩家轻微反冲位移（0.05 tile）——发射的“分量”来源
- **命中迸溅粒子**：一级/零级命中敌人时迸溅 3~5 个小色块向外飞溅 0.15s——打击感核心反馈
- **击碎爆裂**：满蓄力击碎时已有 8 处扇形血迹，【已定：v3.7.2 已实现】加命中点放射同色像素碎片爆发（22 枚细碎：初速 4~14 tile/s / 寿命 0.55s / 尺寸 3~12px）+ 6 枚大块碎片（初速 2~7 tile/s / 寿命 0.8s / 尺寸 10~20px，强化崩解冲击），飞行缩小+渐隐回池，对象池复用，排序层特效(5)）——击碎的"爽点"层次。扩散环（0.2s）仍为待定扩展。
- **受击屏幕红边**：【已定：已实现（v3.7，HurtVignette + GameHud.OnGUI；v3.7.8 加残血脉动）】玩家受击时屏幕边缘短暂红色 vignette（淡入 0.07s / 淡出 0.5s / 峰值 α 0.6）——危险反馈；残血（≤1 心）常驻轻微红晕（α 0.18），并叠加 0.6Hz±40% 正弦呼吸（越残血越紧迫），回满消失（数值文档 3.x）
- **Boss 登场冲击波环**：Boss 登场时地面生成一圈向外扩散的暗色环（0.8s）——登场分量
- **轮次升级光柱**：每轮全灭属性微增时玩家身上短暂上升光柱（0.5s）——成长可见化（对应 5.3 成长方案讨论）

## 14.x 角色头顶消息气泡【已定：M3+ 表现扩展（2026-08-24）】

> 给主角与敌人头顶增加**跟随角色移动的幽默无厘头气泡**，作为灰盒阶段表现力补充，不依赖任何素材（纯 OnGUI 绘制，与现有 HUD 风格一致）。

### 14.x.1 设计目标
- 在适当时机让角色"说一句无厘头的话"——增强幸存者循环中的轻松感与角色感，成本极低（零新资产、纯代码）。
- 气泡**从目标头顶弹出、跟随角色移动**，约 1.5s 显示后 0.5s 淡出消失（总存活约 2s，数值见 `数值文档.md` 第 9 章）。

### 14.x.2 技术路线【已定：OnGUI 灰盒，复用现有 HUD】
- 不引入 UGUI Canvas / 字体资产（避免中文字体回退坑）；气泡由 `SpeechBubbleManager`（`MonoBehaviour`，挂 HUD 同级对象）在 `OnGUI` 中绘制：
  - 维护一组活跃气泡 `{ 跟随目标 Transform, 文案, 计时 }`；
  - 每帧 `Camera.main.WorldToScreenPoint(目标头顶锚点)` 转屏幕坐标 → 画圆角矩形气泡框 + 小尾巴 + 文本；
  - 暂停（`Time.timeScale=0`）时气泡**照常显示并淡出**（用 `unscaledDeltaTime` 计时，与现有 toast 一致）。
- 排序：气泡绘制在最上层（OnGUI 后绘制，天然压在场景之上）。

### 14.x.3 文案数据驱动【已定：纯文本文件 speech.txt，零脚本改动】
- 文案**唯一出处** = `Assets/Resources/Data/Speech/speech.txt`（UTF-8 纯文本）。
  - 格式：`说话者.事件 : 文案1 | 文案2 | 文案3`（`#` 开头注释行，多句用 `|` 分隔）。
  - 说话者：`Player` / `Melee` / `Ranged` / `MeleeSweep` / `Elite` / `Boss`
  - 事件标签：`Spawn`（登场）/ `Hit`（受击）/ `Attack`（出手）/ `Death`（死亡）/ `RoundUp`（主角每轮变强）
- `SpeechBank`（`Assets/Scripts/Data/SpeechBank.cs`）运行时从 txt 解析并按（说话者, 事件）随机抽句；**改文案只改 txt，无需动任何脚本**（代码只放 key 与解析逻辑，符合数据驱动纪律）。
- 可选：仍可用 `SpeechBank` SO 资产（`entries` 字段）在编辑器内覆盖 txt（二选一，互不影响）。

### 14.x.4 接入点【已定】
| 触发时机 | 调用方 | 说话者 / 事件 |
|---|---|---|
| 敌人登场 | `EnemyBase2D.Initialize` / `EnemySpawner2D` 精英·Boss | `Melee`/`Ranged`/`MeleeSweep`/`Elite`/`Boss` / `Spawn` |
| 敌人受击 | `EnemyBase2D.TakeDamage` | 对应类型 / `Hit` |
| 敌人出手 | `EnemyBase2D.ExecuteAttack` | 对应类型 / `Attack` |
| 敌人死亡 | `EnemyBase2D.Die` | 对应类型 / `Death` |
| 主角受击 | `PlayerController.TakeDamage` | `Player` / `Hit` |
| 主角每轮变强 | `EnemySpawner2D.ApplyRoundBonus` | `Player` / `RoundUp` |
| 主角发射（吐槽，可选） | `SlingWeapon` 发射 | `Player` / `Attack` |

- 防刷屏：同一目标同类事件有最小间隔（`SpeechBubbleManager` 去重冷却），避免受击帧每帧冒泡。
