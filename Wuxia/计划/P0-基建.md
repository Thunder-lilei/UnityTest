### 1. URP 渲染管线配置

#### 技术选型

| 项 | 内容 |
|---|---|
| **选择** | URP (Universal Render Pipeline) |
| **原因** | VFX Graph 兼容好、性能适中、学习价值高 |
| **替代方案①** | Built-in RP（旧管线） |
| **不选①** | 不支持 VFX Graph，与项目核心目标（自研 VFX）直接冲突 |
| **替代方案②** | HDRP（高清渲染管线） |
| **不选②** | 面向高端 PC/主机，性能开销大，对学习型 Demo 过重 |

#### 执行步骤

**AI 执行：** 检测到项目创建时已自带 URP 配置，无需额外操作。

**手动操作（如需自行配置）：**
1. 创建项目时选择「URP」模板，或创建后手动添加 URP 包
2. 打开 Edit → Project Settings → Graphics
3. 在 Scriptable Render Pipeline Settings 中指定 URP Asset
4. 当前使用的 URP Asset：`Assets/Settings/URP-HighFidelity.asset`

#### 验证结果
- 检测到渲染管线：`urp`
- URP Asset：`URP-HighFidelity`
- 包版本：`com.unity.render-pipelines.universal 14.2.0-t1`

### 2. Input System 包安装

#### 技术选型

| 项 | 内容 |
|---|---|
| **选择** | Input System (com.unity.inputsystem) |
| **原因** | 事件驱动、可扩展、支持多设备（键鼠/手柄）、学习价值高 |

3. 搜索「Input System」
4. 点击右下角「Install」
5. 安装版本：1.14.4-t3

#### 验证结果

### 4. Input Actions 配置文件

#### 技术选型

| 项 | 内容 |
|---|---|
| **选择** | InputActionAsset (.inputactions 文件) |
| **原因** | Input System 标准配置格式，可视化编辑器支持，代码端通过事件读取，调试方便 |
| **替代方案** | 纯代码定义 InputAction |
| **不选纯代码** | 无可视化编辑器，调试不便，绑定修改需改代码重新编译 |

#### 配置内容

| Action Map | Action | 类型 | 键鼠绑定 | 手柄绑定 |
|---|---|---|---|---|
| Movement | Move | Value (Vector2) | WASD（2DVector 复合） | leftStick |
| Movement | Sprint | Button | LeftShift | leftStickPress |
| Movement | Jump | Button | Space | buttonSouth (A) |
| Combat | Attack1 | Button | 鼠标左键 | — |
| Combat | Attack2 | Button | 鼠标右键 | — |
| Combat | Dodge | Button | Q | — |
| Camera | Look | Value (Vector2) | 鼠标移动 (delta) | rightStick |

#### 执行步骤

**AI 执行：**
1. 通过 C# 脚本使用 InputSystem API 构建 InputActionAsset 对象
2. 添加 3 个 Action Map，7 个 Action，15 个 Binding
3. 调用 `asset.ToJson()` 序列化为 JSON
4. 写入 `Assets/Settings/WuxiaInputActions.inputactions`
5. 通过 `AssetDatabase.ImportAsset` 导入

**手动操作：**
1. 在 Project 窗口 `Assets/Settings/` 文件夹内右键
2. Create → Input Actions
3. 命名为 `WuxiaInputActions`
4. 双击打开 Input Actions 编辑器窗口
5. 点击「+」添加 3 个 Action Map：Movement、Combat、Camera
6. 在每个 Map 下点击「+」添加 Action，设置 Name / Action Type / Expected Control Type
7. 在每个 Action 下点击「+」添加 Binding，设置 Path
8. Move 使用 Add Binding With Composite → 「2D Vector」复合绑定
9. 配置完成后点击「Save Asset」

#### 验证结果
- `AssetDatabase.LoadAssetAtPath<InputActionAsset>` 返回有效资产 ✅
- 包含 3 个 Action Map，7 个 Action ✅

### 6. 核心框架层脚本

#### 技术选型

| 脚本 | 类型 | 选择 | 原因 |
|---|---|---|---|
| IGameEvent | 接口 | 标记接口模式 | 所有游戏事件的基接口，配合 GameEventBus 实现类型安全的事件系统 |
| GameEventBus | 静态类 | 发布/订阅模式 | 解耦系统间通信，AI/战斗/移动互不直接引用 |
| IDamageCalculator | 接口 | 策略模式 | 伤害公式可替换，后期 Lua 重写不改调用方 |
| ISkillLogic | 接口 | 策略模式 | 技能效果可替换，后期 Lua 控制不改调用方 |

**替代方案对比：**

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 接口 + 事件总线（选用） | 类型安全、可测试、Lua 可替换 | 需定义事件类型 | ✅ 选 |
| UnityEvent / SendMessage | 可视化编辑器支持 | 性能差、字符串耦合、无类型安全 | ❌ 不选 |
| Observable / UniRx | 响应式编程 | 需引入第三方库，学习成本高 | ❌ 不选 |

#### 执行步骤

**AI 执行：**
1. 通过 `unity_script.create` 创建 4 个脚本
2. 编译验证：零错误零警告

**手动操作：**
1. 在 Project 窗口 `Assets/Scripts/Core/` 文件夹右键
2. Create → C# Script
3. 依次创建 4 个文件：`IGameEvent`、`GameEventBus`、`IDamageCalculator`、`ISkillLogic`
4. 双击打开编辑器编写代码（代码内容见实际文件）

#### 脚本说明

**IGameEvent.cs** — 标记接口，所有游戏事件实现此接口，通过 GameEventBus 发布/订阅。

**GameEventBus.cs** — 全局事件总线，泛型发布/订阅，支持：
- `Subscribe<T>(Action<T>)` — 订阅事件
- `Unsubscribe<T>(Action<T>)` — 取消订阅
- `Publish<T>(T)` — 发布事件
- `Clear()` — 清除所有订阅（场景切换时调用）

**IDamageCalculator.cs** — 伤害计算接口，定义 `Calculate(baseDamage, attackerLevel, defenderLevel, defense)` 方法。前期 C# 实现，后期 Lua 重写。

**ISkillLogic.cs** — 技能逻辑接口，定义 `OnSkillTriggered(skillId)` 和 `OnSkillHit(skillId, targetId)` 方法。前期 C# 实现，后期 Lua 控制。
